# Trash CLI

## Description

This is a simple trash utility written in C++ That allows you to trash, restore, and empty a trash directory without automatically destructively deleting stuff, like with the `rm` command.

This project is mostly just for fun. I just wanted to have a project to mess around with C++, and I really do like the trash utility that's in Python. So I wanted to make a C++ version to explore more C++ features, understand the language a little bit better, and make sure that I'm keeping up to date with stuff.

## How to Install

Installation is pretty easy.

First, make sure that you have CMake installed. If you don't, install it for your operating system.

Second, you're going to want to `git clone` this repository, `cd` into this repository, and execute the `make` command. That will build the project, and the binary will be output in the `build/bin` directory.

From there, you can add it to PATH. You can do whatever you want with it, really.
